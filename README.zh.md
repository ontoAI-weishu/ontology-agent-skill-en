# 本体论智能体（Ontology Agent）

一个自包含、厂商中立、可移植的 Skill：你装上它、用大白话描述自己的公司，它就把这家公司搭成一套可运行的「本体论」——**知识图谱（语义层）+ 逻辑图谱（逻辑层）+ 决策图谱（决策层）+ 一支 AI 专家团**，并随企业成长可连真实人员与 IM（钉钉/企业微信/飞书）。

> 装一个 Skill，把你的公司变成可运行的智能体系统。

## 快速开始
详见 **`GUIDE.md`**（六步中文引导）：描述企业类型 → 介绍情况 → 搭部门专家团 → 注入老板画像与企业文化 → 注入业务逻辑 → 收优化建议。

入口说明见 **`SKILL.md`**。

## 三种部署形态
- **A 技能包（当前）**：跑在 WorkBuddy 云运行时，订阅即用、零运维；
- **B 云端协同**：端主内、云主外（以面壁 EdgeClaw Box 等为参考实现），敏感数据不出域；
- **C 纯私有化**：整套规范 + 运行时自托管、完全离线（air-gapped），对标 Palantir 的私有部署方向。

三种形态共用同一套厂商中立的本体论规范，换壳即用。
